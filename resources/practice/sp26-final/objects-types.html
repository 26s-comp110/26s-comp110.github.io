Objects & Data Types

1. str literals in Python can be surrounded in either single or double quotes. (T/F)

2. TRUE and FALSE are valid bool values in Python. (T/F)

3. An int literal can begin with a zero, but cannot end with a zero. (T/F)

4. What function can we use to identify the type classification of any object in Python?

5. What is a bool data type? (a) text (b) whole numbers (c) True/False values (d) any type (e) decimal numbers

6. What is an int? (same options as 5)

7. What is a str? (same options as 5)

8. Which of the following literals is a float? (a) 4 (b) "4" (c) 4.0 (d) "4.0"

9. Give the type of each literal: (a) -0.0 (b) "True" (c) True (d) 42 (e) 'C' (f) "42"
